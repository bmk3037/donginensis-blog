- 옆으로 돈 안전모는 `helmet_logo_turn.py`(로고를 안전모 둘레에 감아 붙임: 앞쪽은 넓게, 돌아가는 쪽은 좁고 흐리게). 1_제어반은 `425 226 152 24 180 0.06`(안전모 중심x, 로고 중심y, 안전모 반폭, 앞방향 24도 오른쪽, 로고 폭, 휨).
- 정면 그림 다시 만들기: `python3 helmet_logo.py 원본.jpg 결과.jpg 가운데x 가운데y 로고폭 휨` (1024×1024 정면 그림은 515 205 250 0.10, 돋보기 그림은 515 190 250 0.10, 옆으로 돈 제어반 그림은 470 225 180 0.08).
