## 홈페이지 반복 영상 (`hero/`, 10/24 v2)

- v1(Veo 클립 + 가짜 마크 지우기)은 지저분해서 버림(대표이사 "깨지네, 영상이 지저분하네").
- v2: 플로우 정지 그림 1장(정면, 안전모 앞면 비움)에 진짜 흰 로고를 얹고, `anim.py`로 움직임을 직접 그림: 도감이 옆에서 왼쪽으로 흐르는 데이터 빛줄기 7개, 제어반 초록 표시등이 차례로 깜빡임, 꼭대기 빨간 경고등이 숨쉬듯. 8초 30fps, 끝 = 처음이라 이음매 없음. mp4 0.5MB·webm 0.4MB.
- 플로우 ✦ 표시는 지우지 않음(대표이사 "지우니깐 더러워지더라").
- `홈페이지_도감이_시안.png`: 제목·버튼을 얹은 모습. `embed.html`이 삽입 코드.
