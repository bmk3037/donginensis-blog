# 47편: 꺼 둔 보일러에 혼자 불이 켜집니다 (동결 방지 기능)

10/29 대표이사 "오늘은 무슨 주제를 해야 조회수 1만 돌파를 할까" → "보일러로 기획해줘". 근거: 우리 쇼츠 21편 모두 1,160~1,500회에서 멈춤(첫 시험 노출을 못 넘음), 계속 시청 59.3%. 보일러·난방비 쇼츠는 296만·210만·193만·166만, **3주 전 "보일러 껐다 켜면 가스비 폭탄" 112만**(지금 수요 있음), 10월 말 첫 난방 시기.

## 각도 (난방비 팁은 포화 → 숨은 설비 반전)
| 문장 | 내용 |
|---|---|
| 1~2 | 꺼 둔 보일러에 새벽에 혼자 불 → 고장? 집을 지키는 중 |
| 3~6 | 상식: 집 비울 땐 보일러 끈다 → 바닥 밑 물 배관, 얼면 부피가 커져 배관을 밈 |
| 7~10 | 반전 1: 꺼져도 깨어 있는 장치 → 먼저 펌프, 더 차가우면 불 → 동결 방지 기능 |
| 11~14 | 다시 걸기 "딱 하나 약점" → 반전 2(약 70%): 전기. 코드가 빠지면 작동 안 함 → 플러그 뽑으면 지켜 줄 장치까지 끔 |
| 15~17 | 팁: 끄지 말고 10~15도 또는 외출 모드, 전원은 꽂고 가스·난방 밸브 열기 |
| 18 | 몰랐다면 좋아요, 혼자 사는 가족에게 |

## 사실 확인
| 내용 | 원문 표현 | 출처 |
|---|---|---|
| 동결 방지 기능은 전원이 연결돼야 작동 | "보일러의 전원코드가 콘센트에 꽂혀 있는지 반드시 확인하세요", "동결 방지 운전 기능은 전원이 연결되어야 작동합니다", "겨울철 2~3일 이상 집을 비워 난방을 하지 않을 때에도 각방밸브와 가스 중간밸브를 열어 놓으세요" | [린나이 RC620 사용설명서(PDF)](https://rhpa2.rinnai.co.kr/upload/explain/1752139547863_20250710182559535.pdf) — 검색 결과 인용, 원문 PDF는 서버 503으로 직접 열지 못함 |
| 외출 땐 끄지 말고 10~15℃ 또는 외출 모드, 전원 항상 연결, 밸브 열기, 동결 사고 대부분 배관 | "외출할 때는 보일러를 끄는 대신 실내온도를 10∼15℃로 설정하거나 외출모드(최소온도유지)…", "'동결 방지 기능'이 작동할 수 있도록 보일러 전원을 항상 연결해두고, 가스밸브와 분배기 밸브도 열어둬야한다", "겨울철 보일러 동결사고 대부분은 물이 흐르는 배관에서 발생" | [메트로신문 2021.12.23(귀뚜라미 안내)](https://www.metroseoul.co.kr/article/20211223500029) |
| 먼저 펌프, 더 차가우면 연소 | 귀뚜라미 "2단계 동결 방지"(1단계 순환펌프, 2단계 난방), 경동나비엔 "난방수 온도가 10℃ 이하일 경우 펌프 가동… 6℃ 이하로 내려갈 경우… 보일러가 가동" | 메트로신문 2024.1.22(귀뚜라미, 검색 요약), [경동나비엔 외출기능 설명(블로그)](https://wenlipot.blogspot.com/2018/12/outing.html) |

## 검수 기록
| 걸린 것 | 고친 것 |
|---|---|
| 작동 온도(8·5℃, 10·6℃)가 회사마다 다름 | 대본엔 숫자 없이 "차가워지면 → 더 차가워지면" |
| "꺼 둔"은 조절기 전원을 끈 상태(코드는 꽂힘), 제품마다 다를 수 있음 | 설명란에 "제품마다 다르니 우리 집 설명서 확인" |
| 린나이 설명서 PDF를 직접 못 엶(503) | 검색 인용 문장 + 귀뚜라미 기사 원문으로 교차 확인, 설명란 출처에 둘 다 |
| 수도계량기 동파(서울 하룻밤 95건 등)는 다른 설비 | 한 편 한 주제라 넣지 않음 |
