# 43편: 롯데타워 엘리베이터는 2층짜리 (더블데크 스카이셔틀 + 피난용 엘리베이터)

42편 끝에서 "롯데타워 초고속 엘리베이터" 예고. 10/27 대표이사 "43편 롯데타워 엘리베이터 기획해". 결정 4(0초 움직임, 30~45초, 끝 좋아요·가족 공유·저장 한 줄), 공식 "익숙한 곳 + 처음 보는 숨은 설비 + 숫자". 실사풍, 도감이 끝 두 장면.

→ **각도: "롯데타워 엘리베이터는 2층짜리"(두 칸이 붙어 지하 1·2층에서 같이 탐) + "불나면 엘리베이터 금지 → 롯데타워엔 피난용 19대".** 귀 먹먹·로프·속도 체감은 쓰지 않음.

| 항목 | 내용 |

| 반전 1 | 엘리베이터는 한 칸 → 롯데타워 전망대 엘리베이터는 두 칸이 위아래로 붙은 2층짜리 |

| 팁 | 보통 건물에선 불나면 엘리베이터 말고 계단 / 초고층은 피난안전구역까지 계단으로 |
| 숫자 | 2층, 1초에 10m, 496m, 1분, 기네스(2017), 두 배, 19대 |
| 좋아요·공유 | 10번 "몰랐다면 좋아요, 롯데타워 가는 가족에게", 끝 화면 "저장" 한 줄 |
