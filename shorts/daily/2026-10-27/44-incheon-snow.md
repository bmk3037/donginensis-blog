# 44편: 인천공항 제설 장비 70대 (활주로 제설 + 거대 송풍기)

10/27 대표이사 "한겨울 KTX 선로는 별로 관심이 있을 것 같지 않다" → 고른 주제 "인천공항 활주로". KTX 카드는 `44-rail-switch-heater-HOLD.md`로 보류. 43편 끝 예고도 "인천공항 활주로 편"으로 바꿈(음성 만들기 전). 근거: 07편 인천공항 184km가 계속 시청 77.3%로 채널 최고, 공항·활주로 쇼츠는 100만~470만 회. 결정 4(0초 움직임, 30~45초, 끝 좋아요·가족 공유·저장 한 줄), 공식 "익숙한 곳(인천공항) + 처음 보는 거대 설비(제설 편대·송풍기) + 숫자". 첫눈 전(11월)에 올리면 가장 좋음.

## 검수 기록

| 걸린 것 | 고친 것 |
|---|---|
| 72대는 2023 훈련 때 "동원" 숫자, 눈 올 때마다 다 나가는지 원문 없음 | "출동" 대신 "제설 장비만 70대가 넘어요" |
| 아시아경제 2017 제설 절차·15~30분은 인천공항이라고 적혀 있지 않음(같은 기사 제빙 단락만 인천공항), "가로 6미터 활주로"는 오기로 보임 | "보통 ~ 걸린대요"로 일반 설명, 폭 숫자는 안 씀 |
| 송풍기 숫자는 2014 보도 | 설명란에 연도 |
| 제1~4 활주로 번호별 길이 짝은 확인 못 함 | "3.7km 넘는"(가장 짧은 3,750m 기준) |
| 운항 정보 확인 원문은 제주공항, 인천공항 원문 못 찾음 | 일반 팁으로만, 설명란 출처에 제주공항이라고 씀 |
| 활주로 홈·제빙은 다른 채널이 크게 함 | 홈 뺌, 제빙은 한 문장 |
| 다음 편 도어락: 같은 팁 영상 많음(인생2회차 1,540만, 살림연구소 380만) | 45편 기획 때 각도 다시 확인 |
