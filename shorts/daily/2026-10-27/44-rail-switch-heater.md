# 44편: 한겨울 기찻길 히터 6천 곳 (분기기 히팅 장치 + KTX 착설방지)

43편 끝에서 "한겨울 KTX 선로" 예고. 10/27 대표이사 "그다음 거는?". 결정 4(0초 움직임, 30~45초, 끝 좋아요·가족 공유·저장 한 줄), 공식 "익숙한 곳(기찻길·KTX) + 처음 보는 숨은 설비(갈림길 히터) + 숫자(6,313곳)". 실사풍, 도감이 끝 두 장면. 첫눈 전(11월)에 올리면 가장 좋음.

| 항목 | 내용 |
|---|---|
| 반전 | 겨울 기찻길은 제설차가 치운다 → 갈림길마다 히터가 깔려 미리 녹인다(6천 곳 넘게) |
| 숫자 | 6,313곳(→ "6천 곳 넘게"), 시카고 가스 불, KTX 착설방지제, 언 자갈 |
| 좋아요·공유 | 9번 "몰랐다면 좋아요, 겨울에 기차 타는 가족에게", 끝 화면 "저장" 한 줄 |
| 다음 편 | 인천공항 활주로(07편 인천공항이 계속 시청 77%로 가장 좋았음). **45편으로 꼭 만듦, 숫자는 그때 확인** |

## 검수 기록

| 걸린 것 | 고친 것 |
|---|---|
| 6,313은 "주요 분기기 히팅 장치" 개소 | "6천 곳 넘게", 설명란에 "코레일 2025년 겨울 대책" 표기 |
| 히터가 늘 켜져 있다는 원문 없음 | "켜져 있어요" → "깔려 있어요" |
| 착설방지제는 매번이 아니라 폭설 대비 때 | "눈 오는 날 KTX는" |
| 시카고 불은 다른 채널이 여럿 함 | 훅에서 빼고 비교 한 문장 |
| 분기기가 얼면 신호가 막힌다(연동)는 국내 원문 못 찾음 | "신호" 말 안 씀, "길을 바꿀 수 없어요"만 |
| 분기기 히터 작동 온도·전기요금 원문 없음 | 쓰지 않음 |
| 다음 편 인천공항 활주로 숫자 확인 전 | 예고는 "인천공항 활주로 편"으로만 |
