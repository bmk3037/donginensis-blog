# 49편: 환풍기를 켰는데 담배 냄새가 들어오는 이유 (공조 시리즈 2화)

10/30 대표이사 "다음 화에 프롬프트 수정해서 영상 퀄리티 한번 테스트해보자", 10/31 "지금까지 논의한 대로 주제 정해서 프롬프트 만들어줘, 프롬프트에 들어가는 사진부터 먼저". 공조 시리즈 2화. 근거: 욕실 환풍기 냄새 역류 쇼츠는 498만·296만(10/26 조회수 조사), 아파트 거주자 누구나 겪음, 1화(지하주차장 팬)와 같은 "공기가 지나는 길" 주제.

## 각도 (건축사전 6비트)
| 문장 | 내용 |
|---|---|
| 1~2 | 환풍기를 켰는데 담배 냄새가 거꾸로 들어옴 |
| 3~4 | 집집마다 환풍기 길이 하나의 큰 통로(공용 배기덕트)로 모임 → 한 집 공기가 다른 집으로 샐 수 있음 |
| 5~6 | 반전: 환풍기 뒤에 작은 문(역류방지 댐퍼)이 있어 나갈 땐 열리고 거꾸로 오면 닫힘 |
| 7~8 | 먼지·습기·기름때로 문이 굳으면 열린 채로 냄새가 들어올 수 있음 |
| 9~11 | 팁: 전원 끄고 커버 열어 문 확인 → 닦기 → 안 되면 전동 댐퍼 환풍기 → 테이프로 막지 않기 |
| 12~13 | 계속되면 관리사무소, 이웃에게 공유 |

## 사실 확인 (모두 검색 결과 요약 기준, 본문 직접 못 읽은 것은 표시)
| 내용 | 근거 | 대본 표현 |
|---|---|---|
| 공용 수직덕트에 여러 세대 가지관이 연결된 구조 | [국내 학술 자료(KoreaScience)](https://www.koreascience.or.kr/article/JAKO201711553394903.pdf) 초록: 공용 수직덕트의 상·하부 압력 차이, 가지관마다 댐퍼 | "많은 아파트에선" |
| 댐퍼가 없으면 하층 냄새가 상층으로 | [머니투데이 2020.8.29](https://www.mt.co.kr/society/2020/08/29/2020082817111244155) 분석 소개 | "샐 수도 있죠" |
| 세대별 역류방지 댐퍼 또는 전용 배기덕트 | 국토부 2015.3 주택건설기준 등에 관한 규칙 개정(보도), [2014 입법예고](https://opinion.lawmaking.go.kr/nl4li/lsItptEmp/400294) | **조문·연도 원문 확인 전이라 영상에 안 씀** |
| 스프링·중력식 댐퍼는 먼지·습기·기름으로 열리거나 닫힌 채 고착 | [Green Building Advisor](https://greenbuildingadvisor.com/question/could-a-powered-zone-damper-prevent-leaks-in-a-bathroom-or-kitchen-exhaust) | "굳어 버리기도 해요" |
| 가장 흔한 원인 중 하나가 댐퍼 손상·고착 | [appliancepartspros](https://www.appliancepartspros.com/b/?p=19547) (미국 정비 자료) | 점검 순서 |
| 전동 댐퍼 교체(업체 안내), 전동은 작동 때만 열려 고착 위험이 줄어듦 | 국내 시공 업체 글(광고성) + GBA | "방법도 있어요", 비용 숫자는 안 씀 |
| 테이프로 막으면 습기·곰팡이 | 커뮤니티 답변(약한 근거) | "생길 수 있어요" |

## 검수 기록
| 걸린 것 | 고친 것 |
|---|---|
| "옆집" 담배 냄새로 단정하면 출처 없음 | "담배 냄새", 어느 집인지 말 안 함 |
| 법 조문·연도 원문 미확인 | 대본에서 뺌, 설명란에도 "법령 조문은 확인 필요" 없이 안 씀 |
| 업체 광고 비용(10만~20만 원) | 안 씀 |
| 책임 소재(윗집·관리사무소) 단정 | "공용 덕트 문제일 수 있으니 관리사무소에" |
| 레인지후드 동시 사용·급기 부족 | 신뢰할 출처 못 찾아 뺌(다음 화 후보) |
