## 사실 확인

| 대본 | 근거 |
|---|---|
| 타이어 속 강철선, 5.5밀리 선재에서 시작 | 레이디얼 타이어 보강용 스틸코드는 5.5mm 열간압연 선재를 건식 신선 → 열처리 → 황동 도금 → 습식 신선해 만든다. [고베제강 기술지 KTR No.30](https://www.kobelco.co.jp/english/ktr/pdf/ktr_30/062-065.pdf), [US6076344](https://image-ppubs.uspto.gov/dirsearch-public/print/downloadPdf/6076344) |
| 0.2밀리 안팎 | "finally drawn to 0.15 to 0.40 mm by wet drawing" [US5609013](https://patents.google.com/patent/US5609013) |
| 샤프심 절반보다 가는 | 샤프심 0.5mm(일반 규격)의 절반은 0.25mm, 0.2mm는 그보다 가늚 |
| 많게는 스무 개가 넘는 다이스 | "typically designed to draw wire through a draft of nineteen to twenty-three dies" [US7188503](https://patents.google.com/patent/US7188503). 장비사 습식 신선기 17~25다이스 [Eurodraw](https://expometals.net/en/hall/plants/stand/eurodraw-wire-equipment-srl/products/wet-drawing-lines) |
| 1미터 → 750미터 넘게 | 부피가 같으므로 길이 배수 = (5.5 ÷ 0.2)² ≈ 756 (계산) |
| 뒤 드럼이 더 빨리 | 선이 길어진 만큼 감는 속도가 빨라야 함(부피 일정, 계산 원리). 어긋나면 늘어지거나 끊김 |
| 뜨거워지면 속이 약해져 끊어지기 쉽다 | 선재 온도 상승이 탄소·질소 확산을 빠르게 해 취화·단선 위험을 키움. 층분리(delamination)가 대표 단선 원인 [한국정밀공학회 2006](https://www.koreascience.or.kr/article/CFKO200617054768254.pdf) |
| 다이스가 닳거나 윤활이 나빠지면 당기는 힘이 달라질 수 있음 | 신선력은 마찰·다이 형상에 따라 달라지는 일반 원리. 숫자는 쓰지 않고 "달라지면"으로만 씀 |
| 신선 속도 | 공신력 있는 숫자를 못 찾아 쓰지 않음 |
