# 39편: 꿀팁도감, 멀티탭 구멍 6개면 6개 다 꽂아도 될까?

**결정 3 두 번째 편, 꿀팁도감 새 채널 첫 영상(10/25 대표이사 "다음 편 멀티탭").** 38편 끝에서 예고함. 38편처럼 **전부 클립(문장마다 클립 10개)**, 동작 순간을 단어에 맞춤. 퀴즈 없음, 끝 3문장 저장 → 공유 → 팔로우.

| 항목 | 내용 |
|---|---|
| 공유 대상 | 자취하는 동생, 부모님 댁 → 13번 |
| 저장 장치 | 12번 체크리스트 카드 3초, 고정 댓글 체크리스트 |
| 팔로우 장치 | 14번 "다음엔 겨울 수도 동파 편"(날이 추워지는 때) |
| 말하고 싶은 한 가지 | 구멍 개수가 아니라 와트: 16A × 250V = 4000W, 안전하게는 3200W |
| 그림 | 3D 애니메이션(픽사풍), 시작 그림 10장 + Veo 3.1 Lite 클립 10개, **10개 모두 도감이**(10/25 대표이사 "도감이랑 써야 돼") |
| 38편과 연결 | 같은 아파트(베이지 벽, 나무 바닥, 회색 소파, 복도 벽 차단기함). 38편 끝 장면(멀티탭 들고 손인사)에서 바로 시작, 2번 문장 "지난번 차단기 편에 이어"(10/25 대표이사 "38편이랑 연결되게") |
