# 48편: 지하주차장 환풍기, 언제 돌아갈까요? (공조 시리즈 1화)

10/30 대표이사 "지금 주차장으로 공조시리즈 진행할 거야". 공조 = 건물 안 공기를 다루는 설비. 시리즈 규칙: 한 편 한 주제, 건축사전 결(도감이 없음, 첫 문장 질문, 60~80초), 다음 화는 화면 글자로만 예고.

## 각도
| 문장 | 내용 |
|---|---|
| 1~2 | 환풍기는 언제 도나? → 어떤 단지에선 시간이 아니라 공기가 정한다 |
| 3~6 | 배기가스의 일산화탄소(색·냄새 없음) → 천장 센서 → 기준을 넘으면 환기팬이 저절로 가동 |
| 7~10 | 반전: 공기를 빨아들이는 긴 통이 안 보인다 → 제트팬이 끌어당기지 않고 밀어 보낸다 → 줄지어 밀어 배기구로 |
| 11~12 | 덕트가 줄어 천장 공간을 아낌, 필요할 때만 돌리면 전기도 아낌 |
| 13~15 | 팁: 운전 방식은 단지마다 달라 관리사무소에 문의, 시동 건 채 오래 서 있지 않기, 팬 소리 = 공기를 지키는 중 |
| 16 | 몰랐다면 좋아요, 이웃에게 |

## 사실 확인
| 내용 | 원문 표현 | 출처 | 상태 |
|---|---|---|---|
| CO 센서가 기준을 넘으면 환기팬 자동 가동 | "일산화탄소 자동감지 센서를 설치하여, 농도가 일정 기준을 넘을 경우 주차장 환기휀이 자동으로 자동하여 오염된 공기를 외부로 배출함." | [천안 롯데캐슬 더 두정 단지 소개, 지하주차장 자동 환기시스템](https://www.lottecastle.co.kr/APT/AT00380/13453/info/view.do) | 읽음. 한 단지 안내라 대본은 "어떤 단지에선"으로 한정 |
| 제트팬은 덕트로 끌어당기지 않고 배기 쪽으로 밀어냄 | "pushes air toward exhaust points instead of drawing air from many points", 필요한 높이를 약 4피트 낮춤 | 영문 업계 기사(검색 결과 인용): [parking.net](https://www.parking.net/parking-news/underground-parking-garage-ventilation), [healthcarefacilitiestoday](https://www.healthcarefacilitiestoday.com/posts/New-underground-parking-garage-ventilation-concept-reduces-construction-costs--12641) | 본문 직접 못 읽음. 국내 주차장에 제트팬을 쓴 연구: [제트팬 설치방법에 따른 지하주차장의 CO농도 평가](https://m.earticle.net/Article/A213640)(영남대, 2013, 초록). 대본은 "천장 공간도 아낄 수 있죠"로 완화 |
| 센서 연동 운전은 전력을 아낌 | "start ventilation device according to the CO concentration … to save power energy" | 센서 업체 자료(검색 결과 인용, Winsen) | 업체 주장. 대본은 "아낄 수 있고요" |
| CO는 색·냄새 없음 | 일반 상식 | - | 설명란에 일반 설명만 |
| 법령상 CO 농도 기준 | 주차장법 시행규칙 제6조 제1항 제8호 "…8시간의 평균치가 50피피엠 이하(…실내주차장은 25피피엠 이하)" | 위키 전재(nepla.ai)에서만 확인, 법제처 원문 페이지는 본문이 안 열림 | **원문 확인 전이라 영상·설명란에 숫자 안 씀** |

## 뺀 것 (검수 기록)
| 걸린 것 | 고친 것 |
|---|---|
| "화재 때 같은 팬이 연기 빼는 제연 설비로 바뀐다"는 반전 | 천안시 보도: 현행 법령상 주차장 환기설비는 평상시 매연 관리용이며 화재 시 배연엔 큰 도움이 안 된다고 봄. 조항 확인 불가 → 뺌 |
| "차가 없어도 돈다/멈춘다" 단정 | 운전 방식은 단지마다 다름(센서·그 밖의 방식). "어떤 단지에선"으로 한정 |
| "시간으로 도는 곳도 있다"는 근거 없음 | 대본에서 빼고 "관리사무소에 물어보세요"로 |
| 일산화탄소 ppm 숫자 | 법제처 원문 확인 전엔 안 씀 |
