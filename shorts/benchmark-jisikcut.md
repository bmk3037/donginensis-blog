- 링크: https://www.instagram.com/reels/Dcdf_fpp0_2/ (2026-08-25 업로드, 좋아요 약 8만 2천, 댓글 721)
- 대표이사(10/23): "진짜 딱 원하는 게 이거다. 이것도 전부 플로우잖아. 똑같이 벤치마킹해 보자." → "똑같은 주제로 똑같이 만들어 볼래? 얼마나 똑같이 나오는지" → "이미지만 변경해서?"
- 분석 방법: `yt-dlp`로 받아 1초마다 프레임, 장면 전환 검출, faster-whisper 받아쓰기, ebur128 음량. 받아쓴 원문은 남의 대본이라 공개 저장소에 올리지 않음(아래 "다시 받는 법"으로 새 세션에서 다시 만듦).

## 그림(전부 플로우로 보이는 사실적 3D)

- **사실적인 시네마틱 3D 단면도**: 바닷물(청록) + 해저 지층(회갈색 암반) + 회색 콘크리트. 모든 장면이 같은 색·빛.
- **반복 모티프: 가는 빨간 선 주석** — 치수선, 깊이 눈금자, 빨간 테두리 상자, 과녁 원, 화살표, 빨간 물음표. 장면마다 빠짐없이 있음.
- **빨간 한글 라벨**(흰 테두리, 굵게): "해저터널", "굴착식 해저터널", "방법 1 / 방법 2", "TBM", "NATM", "바닷물 유입?", "충분한 지반 두께", "보령해저터널", "긴 진입구간", "트렌치", "접합부", "기존 함체 / 새 함체", "배수", "바깥 수압", "고무 수밀재", "거가대로", "가덕해저터널", "굴착식 | 침매식". 또렷한 한글은 편집으로 얹은 것, 작은 영문 잡글자(TIK 등)는 플로우가 그린 것으로 보임.
- **움직임**: 1초 간격 프레임을 비교하면 거의 모든 장면에서 카메라가 움직임(다가가기, 돌아가기, 물체 이동) → 클립을 2초 안팎으로 잘라 씀.
- **끝**: 굴착식 | 침매식 좌우 비교 그림 + **시청자 댓글 말풍선**("해저터널 어떻게 만드는지 영상 만들어 주세요" 류) → "댓글 요청에 답한 영상" 형식으로 댓글을 부름.

## 대본 구조 (우리 말로 요약)

| 시간 | 비트 | 하는 일 |
|---|---|---|
| 0–7초 | 훅 | "여기 + 장소 + 놀라운 사실 + 있습니다" → "바로 ~죠" → "그럼 대체 ~할까요?" (우리 GUIDE 3장 훅 공식과 같음) |
| 7–9초 | 갈래 | "대표적인 방법은 두 가지입니다." |
| 9–37초 | 방법 1 | 정의 → 순서 → 세부 방식 둘(TBM, NATM) → **중간 질문** "그런데 ~않을까요?" → 답 → **실제 사례**(보령해저터널) |
| 37–44초 | 다리 | 방법 1의 한계 → "그래서" |
| 44–80초 | 방법 2 | 육상 제작 → 양 끝 막기 → 띄워 예인 → 바다 바닥 도랑 → 탱크에 물 채워 가라앉힘 → **중간 질문 2** "그런데 이음부로 물이 새지 않을까요?" → "아닙니다." → 물을 빼면 바깥 수압이 붙여 줌(고무 수밀재) → 돌로 덮음 → **실제 사례**(거가대로 가덕해저터널) |
| 82–88초 | 정리 | "결국 ~하기도 하고 ~하기도 합니다." |
| 88–91초 | 끝 | "궁금증이 해결되길 바라며, ~은 이렇게 만드는 겁니다." + 댓글 말풍선 |

말투: "~습니다 / ~죠", 문장 짧게, 전문용어는 한 번 쓰고 바로 풀기. 숫자보다 **과정(순서)**과 **질문 → 답**으로 끌고 감.

## 똑같이 만들어 보기(32편 실험) 할 때

1. **시험용(올리지 않음)**: 같은 대본을 타입캐스트로 읽히고, 그림·클립만 우리 플로우로 새로 만들어 "얼마나 똑같이 나오는지" 비교. 남의 대본이라 **이 버전은 올리지 않습니다.**
2. **올릴 버전**: 같은 주제·같은 구조·같은 비주얼 방식으로, 대본은 우리 말로 새로 쓰고 숫자·사례(보령해저터널, 거가대로 가덕해저터널)는 원문 확인(GUIDE 2장).
3. 그림: 사실적인 시네마틱 3D 단면, 청록 바다·회갈색 암반·회색 콘크리트, "thin red annotation lines, dimension lines, depth ruler, red target circles, no text" 모티프를 모든 프롬프트에 넣고, 한글 라벨은 합성에서 얹음.
4. 클립: 약 23개를 만들어 하나를 2컷(앞부분·뒷부분)으로 나눠 45컷. Veo 3.1 Lite 약 230크레딧(하루 50 + 월 1000 안에서 나눠 만들기).
5. 합성: 로고·첫 제목·큰 글자 없이 자막 + 빨간 주석만, 60fps, 끝에 좌우 비교 + 댓글 말풍선(우리 채널 실제 댓글이 없으면 말풍선 대신 질문 자막).

## 다시 받는 법 (새 세션)

```bash
B=<스크래치>/bm2; mkdir -p $B; cd $B
yt-dlp -o "reel.%(ext)s" --write-info-json "https://www.instagram.com/reels/Dcdf_fpp0_2/"
ffmpeg -i reel.mp4 -vf "fps=1,scale=180:-1" f%03d.jpg            # 1초 프레임
ffmpeg -i reel.mp4 -ar 16000 -ac 1 r16.wav                        # 받아쓰기용(faster-whisper small, language=ko, numpy 배열로 넘김)
ffmpeg -i reel.mp4 -vf "select='gt(scene,0.3)',showinfo" -an -f null - 2>&1 | grep -o "pts_time:[0-9.]*"   # 장면 전환
```
