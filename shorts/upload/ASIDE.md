# 꿀팁도감 업로드 지침서 (Aside 에이전트용)

이 지침은 Aside 브라우저의 AI 에이전트가 따르는 문서입니다. 사람(대표이사)은 맨 아래 "Aside에 붙여 넣을 말"만 쓰면 됩니다.
한 편마다 업로드 카드(`shorts/upload/NN.md`)가 있고, 카드에 적힌 글자를 **한 글자도 바꾸지 않고** 그대로 붙여 넣습니다.

## 0. 절대 규칙

0. **승인된 카드만 올린다.** 카드 표의 "승인"이 `예`이고 맨 아래 "올린 기록"이 비어 있는 카드만 올린다. `아직`이면 건드리지 않는다. (대표이사가 완성본을 보고 Claude에게 "올려"라고 하면 Claude가 `예`로 바꾼다.)

1. **채널 확인이 먼저.** 같은 구글 계정에 기존 채널 "숨은 설비 도감"과 새 채널 "꿀팁도감"이 함께 있다. 업로드 전 오른쪽 위 프로필에서 **꿀팁도감**으로 전환됐는지 확인하고, 화면에 보이는 채널 이름을 보고서에 적는다. 인스타·스레드도 **kkultip_dogam** 계정인지 확인한다.
2. **게시 버튼을 누르기 직전에 멈추고 승인받는다.** 채널 이름, 파일 이름, 제목, 공개 설정을 한눈에 보여 주고 "올릴까요?"라고 묻는다. 승인 전에는 게시·예약을 누르지 않는다.
3. **지우지 않는다.** 올린 영상을 삭제하거나 같은 영상을 다시 올리지 않는다(다시 올린 영상은 노출이 거의 없음). 틀린 곳이 있으면 제목·설명·댓글만 고치고, 영상 자체가 틀렸으면 멈추고 보고한다.
4. **카드에 없는 내용을 지어내지 않는다.** 제목, 설명, 해시태그, 댓글은 카드 그대로. 회사 이름은 어디에도 넣지 않는다.
5. 로그인·인증 화면, 캡차, 플랫폼 경고가 나오면 멈추고 사람에게 넘긴다.

## 1. 파일

- 완성본은 GitHub `shorts/media/NN/out/`에 있다(예: `38_breaker_trip.mp4`, `38_cover.jpg`). 먼저 두 파일을 내려받아 맥의 `~/Downloads/꿀팁도감/`에 둔다(GitHub 파일 화면의 다운로드 버튼).
- 카드의 파일 이름과 폴더 안 파일 이름이 같은지 먼저 확인한다. 없으면 멈추고 보고.
- 영상은 세로 1080×1920, 1분 이내, 약 10~20MB. 마지막 1초가 커버 화면이다.

## 2. 순서 (한 편당)

유튜브 쇼츠 → 인스타그램 릴스 → 스레드. 같은 날 같은 시간대에 셋 다 올린다.

### 2-1. 유튜브 (studio.youtube.com, 채널 꿀팁도감)

1. 만들기 → 동영상 업로드 → 카드의 영상 파일 선택.
2. **제목:** 카드 "유튜브 제목" 그대로(100자 이내).
3. **설명:** 카드 "설명" 그대로(체크리스트, 출처, AI 이미지 문구, 해시태그 포함).
4. **썸네일:** 칸이 있으면 카드의 커버 이미지를 올린다. 칸이 없으면 건너뛴다(쇼츠는 영상 마지막 1초가 커버).
5. **시청자층:** "아니요, 아동용이 아닙니다".
6. **자세히 보기:** 변경되거나 합성된 콘텐츠는 "아니요"(만화풍 3D라 실제처럼 보이지 않음). 카테고리는 "노하우/스타일", 언어는 한국어.
7. **공개 설정:** 카드에 적힌 대로(공개, 또는 예약 날짜·시간).
8. 승인 받고 게시. 처리 완료까지 기다렸다가 영상 주소를 적는다.
9. **고정 댓글:** 영상 페이지에서 카드 "고정 댓글"을 그대로 댓글로 달고, 댓글의 ⋮ → "고정"을 누른다.

### 2-2. 인스타그램 릴스 (instagram.com, kkultip_dogam)

1. 만들기(+) → 게시물 → 카드의 영상 선택 → 릴스로 올리기. 비율은 원본(9:16), 자르지 않는다.
2. **커버:** "커버 수정"에서 카드의 커버 이미지를 올린다(안 되면 영상 마지막 프레임 선택).
3. **문구:** 카드 "인스타 글" 그대로.
4. 승인 받고 공유. 올라간 게시물 주소를 적는다.
5. **고정 댓글:** 카드 "고정 댓글"을 댓글로 달고 길게 눌러(또는 ⋯) "고정".

### 2-3. 스레드 (threads.com, kkultip_dogam)

1. 새 스레드 → 카드의 영상 첨부.
2. **글:** 카드 "스레드 글" 그대로(500자 이내, 주제 태그는 카드의 1개만).
3. 승인 받고 게시. 게시물 주소를 적는다.
4. 첫 답글로 카드 "고정 댓글"(체크리스트)을 단다.

## 4. (선택) 하루 뒤 숫자 모으기

24시간 뒤와 7일 뒤에 세 곳의 조회수, 좋아요, 댓글, 공유, 저장(인스타 인사이트, 유튜브 스튜디오 분석의 "조회수 대비 스와이프", "평균 시청률")을 표로 모아 보고한다. 이 숫자로 다음 편 훅과 체크리스트를 고친다.
