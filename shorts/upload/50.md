## 사실 확인 (Claude 10/31, 직접 읽은 것만 확인됨)

| 영상 속 말 | 근거 | 상태 |
|---|---|---|
| 쇠줄 두 가닥이 약 3만 톤 강교를 매닮 | 부산시보 2001.8.2 "광안대로, 현수교 케이블 설치 한창": "직경 60㎝의 주케이블 2개로 연결… 이 주케이블은 무려 3만ｔ의 강교를 달고 있게 된다" | **확인** |
| 지름 60cm, 5mm 강선 312개×37다발 = 11,544가닥 | 같은 기사: "직경 5㎜짜리 312개를 묶은 강선다발 37개… 직경 60㎝, 케이블 가닥수도 1만1544개" | **확인** |
| 다 이으면 약 2만3천 km, 서울~부산 25번 왕복 | 같은 기사: "서울~부산간 25차례 왕복거리인 2만3065㎞" | **확인** |
| 현수교 주케이블 속 습도를 보통 40% 안팎 아래로 유지 | 한국산학기술학회논문지 2018 19권 7호(건설기술연구원): "…주케이블 내부 상대습도를 보통 40%±5% 이하로 유지" | **확인**(현수교 일반) |
| 온도 차로 케이블 속에 물방울(결로) | 연합뉴스 2013.12 기사(카드 인용) | 못 읽음 |
| 속을 조사해 보니 습도가 높아 부식이 걱정된다는 진단 | 연합뉴스 2013.12 기사(카드 인용, 2012 내부 조사) | 못 읽음 |
| 광안대교 케이블 양 끝과 주탑에 제습기를 달고 마른 공기를 밀어 넣음, 습도를 센서로 실시간 감시 | 연합뉴스 2013.12 기사(카드 인용, "설치 예정" 표현일 수 있음) | **못 읽음, 설치 완료·운영 확인 안 됨** |
| 올해도 이 장치를 점검하는 일이 이어짐 | 부산시설공단 2026 유지관리 용역 공고(카드 인용, 조달청 R26BK01401840) | 못 읽음(접속 403) |

참고: 같은 2018 논문은 국내 송기 시스템 설치 교량을 "안면교, 영종교, 울산대교, 이순신대교, 소록대교 총 5개"로 소개하고 광안대교는 넣지 않았다(논문 집계 범위일 수 있음). **연합뉴스 기사와 공고 원문을 읽기 전에는 "광안대교에 제습·송기 시스템이 있다"는 문장을 확정하지 않는다.**
