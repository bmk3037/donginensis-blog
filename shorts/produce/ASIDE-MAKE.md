# 꿀팁도감 제작 지침서 (Aside 에이전트용: 타입캐스트 음성 + 구글 플로우 그림·클립)

편마다 제작 카드 `shorts/produce/NN.md`가 있다. 카드의 글을 **한 글자도 바꾸지 않고** 붙여 넣는다.

## 0. 규칙

0. **저장 이름은 카드에 적힌 것이 우선이다.** 아래 예시(01.jpg, c01.mp4)와 카드가 다르면 카드대로(예 클립판 `s01.jpg`, `c01.mp4`). 카드에 "1단계: 시작 그림", "2단계: 클립"이 있으면 그림을 다 만든 뒤 같은 번호 그림을 시작 프레임으로 클립을 만든다.

0-1. **10/30부터 클립 하나에 샷 3개다(대표이사 "샷을 늘리자", 시험 합격).** 클립 프롬프트가 `Three shots with hard cuts … Shot 1 (0-2.6s) … HARD CUT …`로 시작하면 **그대로 한 번에 넣는다**(그림 1장 = 클립 1개, 8초 전체를 만든다). 카드에 a·b로 나뉜 그림이 있으면 따로 만든다. 클립 프롬프트에 `Audio: natural ambient sound`가 있으면 **소리를 끄지 말고 그대로 받는다**(환경음을 합성에서 쓴다). 카드에 "시험" 표시가 있는 클립(한 클립에 샷 둘)은 한 번만 만들고, 샷이 안 나뉘면 그대로 두고 보고서에 적는다.
1. 카드에 없는 문장·프롬프트를 지어내거나 고치지 않는다.
1-1. **GitHub(공개 저장소)에 올리는 NOTES.md·보고서에는 이메일 주소, 사람 이름, 계정 아이디를 적지 않는다.** 계정은 "Flow 계정 A/B"처럼만 쓴다(2026-10-27 44편 NOTES에서 지움).
1-2. **만들기 직전에 카드를 GitHub에서 다시 열어 최신 내용으로 만든다**(43편은 카드가 고쳐지기 2분 전 내용으로 음성을 만들어 끝 예고를 잘라 냄).
2. 로그인, 캡차, 결제·요금제 화면, 크레딧 부족이 나오면 멈추고 대표이사에게 알린다. 유료 결제는 누르지 않는다.
3. 생성이 실패하면 같은 줄을 **한 번만** 다시 시도. 또 실패하면 그 번호를 건너뛰고 보고서에 적는다.
4. 파일 이름은 아래 규칙 그대로. 번호가 틀리면 영상 장면이 뒤섞인다.

## 1. 타입캐스트 (typecast.ai)

1. 새 프로젝트, 이름 `꿀팁도감 NN`.
2. 캐릭터(목소리): 카드 "목소리"에 적힌 캐릭터. 비어 있으면 타입캐스트 내 프로젝트 중 숏츠(도감이) 프로젝트에서 쓰던 캐릭터를 그대로 쓰고, 보고서에 캐릭터 이름을 적는다. 속도 1.0, 그 밖의 설정은 기본값.
   - 대본은 카드에 "타입캐스트 대본"이 없으면 카드가 가리키는 파일(예 `produce/38.md`)의 대본을 쓴다.
3. 카드 "타입캐스트 대본"을 그대로 붙여 넣는다(한 줄 = 한 문장).
4. 오디오 다운로드 → mp3 → 파일 이름 `voice.mp3`.

## 2. 구글 플로우 그림 (labs.google/flow)

1. 새 프로젝트, 이름 `꿀팁도감 NN`. 세로 9:16, 출력 개수 1.
2. 참고 이미지: `~/Downloads/꿀팁도감/도감이_참고.png`(로고 없는 돋보기 도감이)를 붙인다. 프로젝트 안에서 계속 같은 참고 이미지.
3. 카드 "플로우 그림"의 줄을 **한 줄씩** 넣는다. 각 줄 맨 앞 `01 | ` 같은 번호와 막대는 빼고 그 뒤 문장만 넣는다.
4. 한 장이 나오면 바로 내려받아 **그 줄 번호로** 저장: `01.jpg`, `02.jpg`, … `24.jpg`. 그다음 줄로.
5. 그림 안에 글자·숫자·로고가 크게 들어갔거나, 도감이의 안전모가 파랑이 아니면(노랑·주황 등) 그 줄을 한 번 다시 생성한다.

## 3. 구글 플로우 클립 (Veo 3.1 Lite)

1. 카드 "클립"의 각 항목: "시작 그림"에 적힌 번호의 그림(예 `01.jpg`)을 시작 프레임으로 넣고, 아래 영어 프롬프트를 그대로 넣는다. 모델 Veo 3.1 Lite, 세로 9:16.
2. 내려받아 카드의 클립 이름으로 저장: 예 `c01.mp4`, `c18.mp4`.
3. 크레딧이 모자라면 카드에 적힌 순서(위가 더 중요)대로 되는 데까지만 만든다.

## 4. GitHub에 올리기

1. 주소: `https://github.com/bmk3037/donginensis-blog/tree/claude/shorts-daily/shorts/media` (브랜치가 **claude/shorts-daily**인지 확인).
2. Add file → Upload files. 아래 경로로 올린다(경로는 파일 이름 앞에 폴더를 붙여 만든다).
   - `shorts/media/NN/in/voice.mp3`
   - `shorts/media/NN/in/img/01.jpg` … `24.jpg`
   - `shorts/media/NN/in/clip/c01.mp4` 등
3. 커밋 메시지 `NN: media in`, "Commit directly to the claude/shorts-daily branch" 선택.
