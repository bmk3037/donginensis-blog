# 38편 제작 카드 (클립판): 문장마다 맞춘 클립 10개

10/25 대표이사 "짧은 클립으로만, 전부 움직이게", "대사에 맞게 딱딱 영상이 매칭되도록". 문장 하나(또는 붙은 두 문장)에 클립 하나. 각 클립은 그 문장의 동작 하나만 하고, 합성에서 그 동작의 순간(불꽃, 레버, 불 꺼짐)을 내레이션 단어 시각에 맞춘다. 타입캐스트 대본은 `produce/38.md`와 같음.

- 크레딧: Veo 3.1 Lite 10개 = 100(무료는 하루 50). 무료로는 1일차 c01~c05, 2일차 c06~c10. 유료 크레딧이 있으면 하루에.
- 두 문장 클립(c03, c05, c08, c10)은 앞 3초 = 앞 문장, 뒤 = 뒤 문장.

| 클립 | 문장 | 맞출 말 |
|---|---|---|
| c01 | 1 | 딱 내려갔을 때 |
| c02 | 2 | 0.03초 안에 끊어요 |
| c03 | 3·4 | 신호예요 → 전부 뽑아요 |
| c04 | 5 | 끝까지 내렸다가, 한 번만 올려요 |
| c05 | 6·7 | 하나씩 꽂아 → 딱, 범인 |
| c06 | 8 | 벽 속 배선 |
| c07 | 9 | 전문가 점검 |
| c08 | 10·11 | 테스트 버튼 → 딱 내려가면 정상 |
| c09 | 12 | 저장해 두면 |
| c10 | 13·14 | 보내 주세요 → 팔로우 |

## 합성에서 맞추는 법

1. 받아쓰기(단어 시각)로 맞출 말의 시각을 잡는다(예 7번 "딱").
2. 클립에서 동작 순간을 찾는다(밝기가 확 바뀌는 프레임 = 불꽃·불 꺼짐, 움직임이 가장 큰 프레임 = 레버).
3. 동작 순간이 그 단어에 오도록 클립 시작점을 옮기고, 문장 끝에서 자른다. 모자라면 0.8~1.2배로 속도만 살짝 조절.
