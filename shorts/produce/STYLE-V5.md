# 형식 C: 수수께끼형 (2026-11-01 확정 제안, 55편부터)

근거: 우리 40편 전부 1,300회 벽(`shorts/channel-feedback.md` 11/1), 같은 방식 새 채널 돈의 구조물·도시해부도는 2달 만에 10만+ 15~22편(`shorts/benchmark-newchannels-2026-11.md`), 이탄생 삼성역·김포(`shorts/benchmark-2tan-samsung.md`), 53·54편 실수와 재검토(STYLE-V4 14·16절, `shorts/produce/54.md`). **STYLE-V4의 화면 규칙은 그대로 쓰고, 대본·주제·운영을 이 문서가 바꾼다.**

## 1. 주제 고르기 (셋 다 통과)
1. **짐작 안 되는 수수께끼가 있나**: "○○인데 왜 △△일까?"를 한 줄로 쓸 수 있고, 답을 10명 중 8명이 모름. (예: 롤러가 없는데 무엇이 벨트를 받칠까 / 자갈은 늘 있는데 왜 겨울에만 튈까)
2. **같은 각도 쇼츠가 30만을 안 넘었나**: 유튜브 API 검색(`ytsearch.py`)으로 확인. 해외 영상만 크면 오히려 좋음(수요 증명 + 한국 빈자리).
3. **원문 숫자가 있나**: 수수께끼의 답과 숫자 3개 이상을 원문 인용으로 확인(못 읽은 숫자는 안 씀).
- 덤(있으면 더 좋음): 지금 이유(뉴스 2주 안·계절), 보는 사람과 가까움(KTX·아파트·고속도로). 공장·현장 이야기도 됨(삼척 47.8만).

## 2. 대본 (20~24문장, 80~90초)
| 구간 | 할 일 |
|---|---|
| 1~2문장(4초) | 눈에 보이는 장면 + 숫자/이상한 점. 첫 문장 2~3초. **답 금지** |
| 3~5문장 | 짐작되는 부분은 먼저 말해 버리고, 짐작 안 되는 질문 하나를 남김 → "그런데 왜 ~일까요?" |
| 6~11문장 | 단서 → 과정 → **35~40초에 답**(그림으로 센 장면) |
| 12~16문장 | 두 번째·세 번째 작은 수수께끼("그럼 ~은?") 와 숫자 |
| 끝 2문장 | 보낼 사람 지정 + 채널 이름 문장("…이런 이야기가 숨어 있었습니다") |
- **던진 질문은 반드시 답한다**(54편: "12년째 놀고 있다"의 이유를 끝내 말 안 함 → 금지).
- 문장은 쉼표마다 끊어 **한 덩어리 2~3초**. 원리 설명도 질문에 대한 답의 과정일 때만 넣는다(54편 가운데 30초 원리 설명이 질문과 따로 놂).
- "당신이 ~에 있다면"처럼 보는 사람을 장면에 넣는 문장 1개.
- 제목 = 첫 문장 또는 "[장소] + [숫자·사물] + [의외의 방식]" 서술형.

## 3. 화면 (STYLE-V4 + 14·16절 그대로)
- 카드 맨 위 **움직임 규칙** 한 줄 → 모든 클립 프롬프트에 영어로. 같은 설비는 모든 그림에서 같은 모양.
- **1080p만**. 연속 장면 20초 이상(이어지는 클립은 Claude가 끝 프레임 확인 뒤 생성, "끝이 어디로 가면 안 되는지" 명시).
- 답이 나오는 순간(35~40초)이 가장 센 그림이 되게 클립을 배치(예: 바닥 얼음이 떨어져 자갈을 때리는 장면).
- 숫자는 전부 합성으로 크게. 클립 속 글자는 4~6자 표지판만.
- 한 컷 3~4초(최대 4.5초), 연속 장면만 예외.

## 4. 합성·검사 (Claude, 순서 고정)
1. 재료 받으면 **클립 검수**(0.5초 모아보기: 움직임 규칙·깨진 글자·녹는 형태·사람 사라짐)
2. **말·화면 대조표**(문장 → 클립 구간 → 실제 보이는 것), 요청끼리 부딪치면 렌더 전에 묻기
3. 렌더 → **1초 모아보기 전체 + 받아쓰기**로 다시 훑기 → 수치(길이·LUFS·정지)와 함께 보고. 어긋난 곳 숨기지 않기
4. 레시피 파일 커밋

## 5. 운영
- 업로드: 하루 1편 이상, 같은 시각. 몰아 올리기·B2B 금지. (새 채널 경쟁자는 하루 4~8편 → 크레딧·Aside가 되는 만큼 늘림)
- 고정 댓글은 답하기 쉬운 질문 1개, 댓글엔 전부 답.
- **24시간 뒤 계속 시청(스와이프 안 한 비율) 기록** → 70% 넘는 편의 주제·첫 문장 형태를 다음 편에 복제. 54편(훅판)이 첫 비교 기준.
- 인스타 계정 이름 "숨은설비이야기"로 맞춤. API 연결(`shorts/API-SETUP.md`) 뒤 업로드·숫자 수집은 Claude.
- 음성: 타입캐스트 API(문정), Claude가 만듦.

## 7. 11/1 추가 분석 반영 (대표이사가 붙여 준 별도 분석: 건축사전 상위 10편 390만+, Gemini 영상 분석 가능)
- **첫 문장 틀(건축사전)**: "여기 [익숙한 장소]에는 [상식과 모순되는 사실]이 있습니다." → 2절 "1~2문장 = 장면 + 이상한 점"의 한 가지 쓰는 법으로 채택. 장소가 없는 주제(55 KTX)는 "[익숙한 것]이 [상식과 반대로] ~합니다"로.
- **화면**: 3D 부감 → 단면 그래픽 전환, **4초쯤 핵심 단어를 크게**. 우리 합성의 큰 글자(num3d) 위치를 4초 안팎에 하나 둔다.
- **자막 위치**: 건축사전은 하단 중앙. 우리는 10/28부터 화면 가운데(대표이사 결정). 바꿀지는 대표이사가 정함(A/B 비교 후보).
- **주제 후보 검증(11/1 유튜브 API)**: 신월 빗물저류배수시설은 **비어 있지 않음** — 건축사전 177만(10/26 조사) + 8~10월 작은 채널 4곳(미친 설계 3만, 이유 있는 설계 1.6만 등). 방재실·화재수신반은 **수수께끼가 있음**: KBS 자막뉴스 62.5만 "오작동에 화재경보기 꺼버린 관리사무소, 3분 뒤 진짜 불"(2022). 같은 각도의 설명형 쇼츠는 시설관리 채널의 실무 영상(15~30만)뿐 → 56편 1순위 후보(회사 전문성과도 맞음, 회사 이름은 여전히 안 씀). 수치(비화재보 비율 등)는 원문 확인 전.
- **Gemini 영상 분석(대표이사 쪽 도구)**: 우리 세션은 유튜브 영상 다운로드가 봇 확인으로 막힘 → 터진 영상의 첫 5초 화면·컷 시각·자막 위치·큰 글자 순간은 Gemini 분석 결과를 받아 `shorts/benchmark-*.md`에 붙인다.

## 8. Gemini로 잰 터진 영상 공통점 (11/1, `shorts/benchmark-gemini/`)
- 첫 장면은 **4초 동안 끊지 않는 부감 하나** + **0초부터 큰 글자 하나**(숫자나 장소 이름, 3~4초 유지).
- 숫자 큰 글자 밑에 **작은 설명 한 줄 + 출처**(예: "800만 톤 / 1년에 캐는 석회석 / 삼표 2025"). 우리 합성의 num3d에 설명·출처 줄을 붙인다.
- 자막: 두 영상 모두 **아래 가운데**, 2~4어절, 흰 글씨 + 검은 테두리. (우리는 가운데 → 대표이사 결정 필요, 55편부터 아래 가운데 권장)
- 컷 22~30개/96초, 장면 종류를 계속 바꿈(부감 → 실내 → 단면 → 1인칭 → 눈높이).
- 끝 화면 글자: "**이 일 하시는 분이 보신다면, 틀린 데를 알려 주세요**" 식 전문가 댓글 유도(우리 채널 이름·설비 주제와 잘 맞음). 구독 유도는 없음.
- 문장 길이보다 **질문이 끝까지 남아 있느냐**가 중요(한강은 문장 5~6초여도 651만).

## 9. "정밀 모방 4단계" 적용 (11/1, 유튜브 '애드' 영상 음성 요약, 대표이사 공유)
1. **병목 하나 찾기**: 쇼츠는 클릭률보다 **계속 시청(스와이프 안 한 비율)**이 첫 관문. 우리 병목 = 첫 2초(채널 평균 61%, 목표 70%+). 30초 시청률 60% 아래면 대본 앞부분 문제.
2. **레퍼런스 3개**: 이탄생(삼성역·김포), 신비한 건축사전(한강), 돈의 구조물(삼척).
3. **핵심 요소 1~2개만**(파레토): ① 0초 모순·결론 숫자 첫 문장 + 큰 글자 ② 질문을 끝까지 남김. 나머지(그림체·자막 위치·길이)는 한 번에 같이 바꾸지 않는다.
4. **A/B 시험, 한 번에 하나만 바꿈**: 같은 편의 첫 6초만 다른 두 판 → 하나는 본 게시, 하나는 **인스타 "시험용 릴스"(팔로워 아닌 사람에게만 노출)**로 올려 24시간 계속 시청·평균 시청 시간 비교. 이긴 쪽이 다음 기준. 4~5번 반복.
- 반성: 10/21~11/1 동안 형식·길이·그림체·제목을 매번 여러 개씩 동시에 바꿔서 무엇이 효과였는지 알 수 없었음 → 55편부터 **한 편에 한 가지만** 바꾼다.
