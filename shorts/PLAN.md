## 1. 동인엔시스가 하는 일 (영상의 바탕)

**한 문장:** 모터로 도는 설비의 제어반을 직접 설계·제작하고, 그 제어반에서 설비 데이터를 모아 연결합니다. 슬로건은 "설비를 제어하고, 데이터를 연결하다."

**핵심 제품: 지능형 제어반**
- 설비를 제어하면서 모터 권선·베어링 온도, 진동, 전류, 전력을 24시간 기록합니다.
- 기준을 넘으면 알리고, 통신이 끊겨도 보관했다가 다시 보냅니다.
- 설비는 그대로 두고 제어반만 바꾸며, 1~2대부터 시작할 수 있습니다.

**사업 분야와 현장** (✅ company.md 실적, 🔄 진행 중이라 실적으로 쓰지 않음)

## 2. 지키는 선

- **그림:** 영상 그림은 모두 AI로 만듭니다(구글 플로우 등). 실제 현장이나 고객 설비처럼 말하지 않습니다. 설명란에 "AI로 만든 이미지"를 밝힙니다.
- **고객사 이름:** 영상·커버·설명란에 넣지 않습니다. 설비 이야기로만 풉니다.
- **동인엔시스 이름:** 공개 영상에는 넣지 않고 설명란에만 넣습니다. 고객 제안용(13-C 같은 것)만 커버에 로고를 넣습니다.
- **실적:** 🔄 진행 중인 일은 실적처럼 말하지 않습니다. 끝나면 company.md에 넣고 나서 씁니다.
- **표현:** "AI가 고장을 예측한다"고 하지 않습니다. "기록하고, 기준을 넘으면 먼저 알린다"로만 씁니다. 모든·항상·반드시 같은 일반화도 쓰지 않습니다.
- **숫자:** 출처 없는 숫자는 쓰지 않습니다. 경쟁사가 낸 추정치는 "업계 추정"으로 표기합니다.
- **편마다 뼈대(structure.md 0장):** 멈추면 곤란한 설비 → 그 설비를 돌리는 제어반 → 돌리기만 하는 제어반의 한계 → 지능형 제어반(제어 + 데이터 연결)
- **화면:** 첫 1초는 커버, 9:16, 94~100초입니다(고객 기술판은 예외).

6. **커버:** 타이어 속 강철의 비밀 / 쇠를 / [당겨서] / 뽑아낸다 / 어디에 쓸까?

### 19 · C2 선박 주배전반
1. **훅:** 여기, 배 한 척의 전기를 전부 나눠 주는 상자가 있습니다.
2. **궁금증:** 대체 이 상자가 꺼지면 어떻게 될까요? → 블랙아웃, 바다 한가운데서 배가 멈춤
3. **숫자:** 배전반 고장의 4분의 1이 풀린 접속부·과열점 ([ABB 기술자료](https://library.e.abb.com/public/9cec6142465543c0956bccf2033626ff/LE_STM(EN)-_1VCD000641.pdf)) / 배의 진동이 접속부를 풀리게 함
4. **고리:** 흔들리는 배 → 접속부 온도·전류를 계속 기록, 기준 넘으면 알림
5. **영업 대상:** 조선소·선주·선박 전기장비사
6. **커버:** 배 안 전기의 비밀 / 배 한 척의 / [전기를 전부] / 나눠 주는 상자 / 이게 꺼지면?

### 20 · C3 선박 공조
1. **훅:** 여기, 전기의 3분의 1을 에어컨이 쓰는 배가 있습니다.
2. **궁금증:** 대체 배가 왜 그렇게 에어컨을 많이 쓸까요? → 여객선·군함의 거주구역, 제어실, 식품 냉동창고
3. **숫자:** 여객선 HVAC가 전체 에너지의 최대 3분의 1 ([Riviera 2026](https://www.rivieramm.com/news-content-hub/news-content-hub/why-passenger-ships-cannot-afford-to-ignore-this-hidden-power-drain-88782)) → 보강 필요
4. **고리:** 압축기·송풍기 모터가 바다에서 멈추면 고칠 사람이 없음 → 상태 기록, 먼저 알림
5. **영업 대상:** 조선소·선박 공조사
6. **커버:** 바다 위 에어컨의 비밀 / 배 전기의 / [3분의 1]을 / 에어컨이 쓴다 / 왜 그렇게 많이?

### 21 · A5 LNG 극저온 펌프
1. **훅:** 여기, 영하 160도 액체 속에 잠겨서 도는 모터가 있습니다.
2. **궁금증:** 대체 모터를 왜 액체 속에 넣을까요? → 탱크 안에서 LNG를 바로 퍼 올리는 펌프
3. **숫자:** 영하 160℃ 이하에서 LNG 이송, 평택기지 7개월 실증, 2025년 국산화 ([시사경제 2025](https://sateconomy.co.kr/news/view/1065596978038020))
4. **고리:** 탱크 안이라 꺼내 볼 수 없음 → 밖에서 전류·진동으로 상태를 읽어 기록, 먼저 알림
5. **영업 대상:** 가스공사·LNG 기지·펌프사
6. **커버:** LNG 기지의 비밀 / [영하 160도] / 액체 속에서 / 도는 모터 / 왜 잠겨서 돌까?
7. **주의:** 11편(BOG)과 같은 LNG 계열이라 간격을 둡니다.

### 22 · C4 하이브리드 추진 병원선
1. **훅:** 여기, 섬마을을 돌며 디젤과 전기를 번갈아 쓰는 병원이 있습니다.
2. **궁금증:** 대체 병원이 왜 배 위에 있을까요? → 섬 주민 진료선, 항구에선 전기로 조용히
3. **숫자:** 충남병원선 G/T 330톤급, 2023년 8월 취항(company.md) → 외부 출처 보강 필요
4. **고리:** 디젤엔진과 전기모터를 하나로 제어(추진 통합제어), 모터·배터리 상태 기록
5. **영업 대상:** 지자체·관공선·조선소
6. **커버:** 바다 위 병원의 비밀 / 디젤과 [전기]를 / 번갈아 쓰는 / 병원선 / 왜 배 위에 병원이?
7. **주의:** 실적이지만 선박·기관 이름은 공개 허락을 받은 뒤에만 씁니다.
