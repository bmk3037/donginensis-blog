# 알고보니 디자인 의뢰서 (ChatGPT용, 11/9 대표이사 "디자인은 챗지피티 시켜")

공통(처음에 한 번 붙여 넣기):
```
채널 이름은 "알고보니"야. 한국 유튜브 쇼츠·인스타 릴스 채널로, "누구나 아는 곳과 물건의 숨은 사연과 반전"을 1분 영상으로 알려 줘. 영상은 미니어처 3D 느낌의 밝은 도시 그림이야. 브랜드 색은 진한 남색(#0A2A55), 흰색, 포인트 노란색(#FFD43B). 글꼴은 굵고 둥근 고딕(프리텐다드 ExtraBold 느낌). "알고"는 흰색, "보니"는 노란색으로 두 색으로 쓰는 게 로고의 핵심이야. 글자는 반드시 한글 "알고보니"가 정확히 나와야 해(다른 글자·영문 금지). 아래 시안 5개를 따로따로 만들어 줘.
```

## 1. 프로필 이미지 (유튜브·인스타 공통)
```
시안 1: 프로필 이미지 800x800 PNG. 진한 남색 배경, 가운데에 "알고보니" 큰 글씨(알고=흰색, 보니=노란색). 원형으로 잘려도 글자가 안 잘리게 글자는 원 안쪽 여백을 충분히 줘. 작은 크기(48px)에서도 읽히게 단순하고 굵게. 장식 최소(얇은 흰 원 테두리 정도).
```

## 2. 유튜브 영상 워터마크 (스튜디오 > 맞춤설정 > 브랜딩)
```
시안 2: 투명 배경 PNG 150x150. 남색 원 안에 흰 테두리, 가운데 "알고보니"(알고=흰색, 보니=노란색). 영상 오른쪽 아래에 작게 떠도 읽히게 굵게.
```

## 3. 영상 왼쪽 위 워터마크 배지 (영상 안에 항상 표시)
```
시안 3: 투명 배경 PNG 가로 480 x 세로 180. 남색 알약(캡슐) 모양에 흰 테두리, 안에 "알고보니"(알고=흰색, 보니=노란색). 글자는 알약의 70% 이상 크기로 크고 굵게. 밝은 항공 그림 위에서도 잘 보이게 테두리를 진하게.
```

## 4. 유튜브 배너
```
시안 4: 배너 2560x1440 PNG. 진한 남색 배경, 가운데 안전 영역(1546x423) 안에 "알고보니"(알고=흰색, 보니=노란색) 큰 글씨와 그 아래 작은 한 줄 "누구나 아는 곳의 숨은 사연". 배경에는 아주 옅은 도시 미니어처 실루엣만.
```

## 5. 섬네일 표준 틀 (모든 영상 공통, 장소 이름만 바꿈)
```
시안 5: 세로 1080x1920 섬네일 틀. 배경은 내가 올릴 도시 항공 그림. 규칙: ① 장소 이름 한 단어~두 줄만 아주 크게, 흰색 글씨에 진한 남색 두꺼운 테두리와 그림자, 가운데(세로 약 50%) ② 노란 글씨·숫자·물음표 없음 ③ 글자 뒤에 어두운 반투명 띠(글자가 밝은 배경에서도 읽히게) ④ 왼쪽 위(세로 280~370px 구간)에 "알고보니" 알약 워터마크 ⑤ 인스타 프로필 격자(가운데 1080x1440) 안에 글자와 워터마크가 모두 들어가야 해. "마린시티"라는 장소 이름으로 예시 1장 만들어 줘.
```
