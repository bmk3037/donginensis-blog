# 꿀팁도감 자동화 (2026-10-24 대표이사: "채널만 만들고 영상도 자동화할 거야", "음성은 타입캐스트, 구글 플로우에서 이미지·클립")

사람은 채널을 만들고, 완성본을 한 번 보고 "올려"만 한다. 나머지는 클라우드 세션(Claude)과 Aside(맥 브라우저 에이전트)가 나눠 한다.
타입캐스트·구글 플로우는 클라우드에서 부를 수 있는 API가 없어서, 로그인된 브라우저를 쓰는 Aside가 맡는다. 파일은 GitHub로 주고받는다.

## 흐름 (한 편)

| 순서 | 누가 | 하는 일 | 결과물 (브랜치 `claude/shorts-daily`) |
|---|---|---|---|
| ① | Claude | 주제(`daily/topics.md` 다음 후보) → 사실 확인 → 대본 → 검수 → 제작 카드 | `daily/날짜/NN-slug.md`, `produce/NN.md` |
| ② | Aside | 제작 카드대로 타입캐스트 mp3, 플로우 그림 24장(한 줄씩 생성해 바로 `NN.jpg`로 저장), 클립 2개 → GitHub에 올림 | `media/NN/in/voice.mp3`, `media/NN/in/img/01.jpg~24.jpg`, `media/NN/in/clip/cNN.mp4` |
| ③ | Claude | 받아쓰기로 음성 확인 → 합성 → 커버 → 업로드 카드 → 완성본 올림 → 대표이사에게 알림 | `media/NN/out/NN_slug.mp4`, `media/NN/out/NN_cover.jpg`, `upload/NN.md` |
| ④ | 대표이사 | 폰으로 완성본 한 번 보기. 괜찮으면 Aside에 "NN 올려" | - |
| ⑤ | Aside | `upload/ASIDE.md` 지침대로 유튜브 → 인스타 → 스레드 | `upload/NN.md` 맨 아래 "올린 기록" |

- ②에서 그림 번호를 Aside가 생성 순서대로 바로 붙이므로, 합성 때 번호 맞추기가 필요 없다.
- ④ 확인은 빼지 않는다: 안전 팁은 틀리면 위험하고, 올린 뒤에는 지우고 다시 올리지 않기 때문.
- 플로우 무료 크레딧은 하루 50(Veo 3.1 Lite 클립 1개 10). 하루 1편이면 클립 2개까지가 안전.

## 예약 (대표이사가 시각을 정하면 설정)

| 무엇 | 누가 | 제안 시각(한국) |
|---|---|---|
| ① 기획·대본·제작 카드 | Claude 예약 작업(새 세션) | 매일 07:00 |
| ② 음성·그림·클립 | Aside 루틴 | 매일 09:00 |
| ③ 합성·알림 | Claude 예약 작업(새 세션) | 매일 12:00 (파일이 없으면 15:00에 한 번 더) |
| ⑤ 업로드 | 대표이사가 확인 뒤 Aside에 지시 | 저녁 |

## 파일 크기

- 한 편에 그림·클립·음성 약 20~30MB가 저장소에 쌓인다. 쌓이면 `media/`를 별도 브랜치나 드라이브로 옮긴다(브랜치 추가는 대표이사 허락 뒤).
