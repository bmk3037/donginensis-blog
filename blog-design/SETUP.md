# 네이버 블로그 직접 세팅하기 (PC, 처음부터 끝까지)

준비물: PC 크롬(또는 엣지), 받은 `blog-design.zip` (압축 풀어 두기)
걸리는 시간: 40분~1시간. 중간에 언제든 멈췄다가 다시 해도 됩니다.
※ 네이버 화면 메뉴 이름은 시기에 따라 조금씩 다를 수 있습니다. 비슷한 이름을 찾으면 됩니다.

---

## 0단계. 관리 화면 들어가기

1. 크롬에서 **naver.com** → 오른쪽 위 **로그인** (회사 블로그 계정)
2. 주소창에 **blog.naver.com/bmk3037** 입력 → 엔터 (이 디자인은 bmk3037 · 현장 이야기 블로그용)
3. 블로그 화면에서 프로필 사진 아래(또는 오른쪽 위) **관리** 버튼 클릭
4. "블로그 관리" 화면이 열립니다. 위쪽에 탭이 있습니다:
   **기본 설정 / 꾸미기 설정 / 메뉴·글·동영상 관리 / 내 블로그 통계**
   → 아래 단계에서 이 탭들을 오가며 설정합니다.

> 💡 지금 디자인을 혹시 되돌리고 싶을 때를 대비해, 시작 전에 블로그 첫 화면을 캡처해 두세요.

---

## 1단계. 이미지 주소 만들기 (버튼·배너용) — 5분

위젯(사이드 버튼)에는 이미지 파일이 아니라 **이미지 인터넷 주소**를 넣어야 합니다. 비공개 글을 하나 만들어 주소를 얻습니다.

1. 블로그 화면으로 돌아가 **글쓰기** 클릭
2. 제목: `디자인 이미지 보관용 (비공개)`
3. 위쪽 도구막대의 **사진** 아이콘 클릭 → 압축 푼 폴더의 `images`에서 아래 파일을 선택해 올리기
   - `btn-1-home.png`, `btn-2-panel.png`, `btn-3-check.png`, `btn-4-partner.png`, `btn-5-profile.png`
   - (선택) `banner-inquiry.png`, `banner-partner.png`
   - 여러 장을 올릴 때 "사진 배치"를 물으면 **개별사진** 선택
4. 오른쪽 위 **발행** 클릭 → 공개 설정을 **비공개** 로 바꾸고 → **발행**
5. 발행된 글이 열리면, 각 이미지에 마우스를 대고 **오른쪽 클릭 → "이미지 주소 복사"**
6. 메모장을 열고 아래처럼 순서대로 붙여넣어 둡니다
   ```
   버튼1 홈페이지: (붙여넣기)
   버튼2 지능형제어반: (붙여넣기)
   버튼3 진단신청: (붙여넣기)
   버튼4 IT협업: (붙여넣기)
   버튼5 회사소개서: (붙여넣기)
   ```
   - 주소는 보통 `https://postfiles.pstatic.net/....png?type=w...` 모양입니다. 그대로 쓰면 됩니다.

## 2단계. 기본 정보 — 5분

**관리 → 기본 설정 → 블로그 정보**

| 칸 | 입력 |
|---|---|
| 블로그명 | `동인엔시스 현장 이야기` |
| 별명 | `동인엔시스` |
| 소개글 | `1991년부터 산업·선박 제어반을 설계·제작해 온 (주)동인엔시스 공식 블로그입니다. 지능형 제어반과 산업설비 데이터 이야기를 전합니다. ☎ 051-862-3668` |
| 내 블로그 주제 | `비즈니스·경제` (또는 `IT·컴퓨터`) — 한 번 정하면 바꾸지 않는 것이 좋습니다 |
| 블로그 프로필 이미지 | **등록** → `profile.png` 선택 |

맨 아래 **확인** 클릭.

## 3단계. 스킨 고르기 — 3분

**관리 → 꾸미기 설정 → 스킨 선택**

1. 무늬·그림이 거의 없는 **흰색 계열 단순한 스킨**을 하나 클릭 (우리 배너로 덮을 것이라 단순할수록 좋음)
2. **스킨 적용** 클릭

> 지금 쓰는 디자인을 유지하고 이미지만 바꿀 거라면 이 단계는 건너뛰세요.

---

## 4단계. 레이아웃 — 5분

**관리 → 꾸미기 설정 → 레이아웃·위젯 설정**

1. 위쪽 레이아웃 그림 중 **본문 + 오른쪽 사이드바(2단)** 모양 클릭
2. 오른쪽 위젯 목록에서 필요 없는 것은 체크 해제 (예: 날씨, 시계, 방문자 그래프, 지도 등)
3. 남겨 둘 것: **프로필, 카테고리, 검색, 최근 글** 정도
4. 아래쪽 **적용** 클릭 (아직 버튼 위젯은 6단계에서 추가)

---

## 5단계. 상단 큰 배너 — 10분

**관리 → 꾸미기 설정 → 세부 디자인 설정**
화면 오른쪽에 **리모콘**(설정 상자)이 뜹니다.

### 5-1. 스킨배경에 배너 넣기
1. 리모콘에서 **스킨배경** 클릭
2. **디자인** 항목에서 **직접등록** 선택
3. **파일 등록** → `hero.png` 선택
4. 옵션:
   - 위치: **가운데 · 위**
   - 반복: **반복 없음**
   - 배경색(컬러): **흰색 (#FFFFFF)**

### 5-2. 타이틀 영역 맞추기
1. 리모콘에서 **타이틀** 클릭
2. **블로그 제목** 표시 → **체크 해제** (배너에 이미 문구가 있으므로)
3. **영역 높이**: 처음엔 **500**으로 넣고, 미리보기를 보며 조정
   - 배너 아래쪽 글자(상담문의 051-862-3668)가 블로그 본문에 가려지면 → 높이를 **늘리기**
   - 배너와 본문 사이에 빈 공간이 너무 크면 → 높이를 **줄이기**
   - 타이틀 디자인(이미지)은 넣지 않습니다 (배경이 보이도록)

### 5-3. 적용
- 리모콘 아래 **적용** 클릭 → "적용하시겠습니까?" **확인**
- 내 블로그를 새 탭으로 열어 확인 (F5로 새로고침)

> 배너가 화면 폭보다 작게 보이거나 잘리면, 지금 모니터 해상도를 알려 주세요. 크기를 맞춰 다시 만들어 드립니다.

---

## 6단계. 버튼 위젯 넣기 — 10분

**관리 → 꾸미기 설정 → 레이아웃·위젯 설정**

1. 위젯 목록 아래쪽 **+ 위젯직접등록** 클릭
2. **위젯명**: `홈페이지`
3. **위젯코드입력** 칸에 아래 코드를 붙여넣고, `이미지주소` 글자를 지우고 1단계 메모장의 **버튼1 주소**를 넣기
   ```html
   <a href="https://donginensis.com/?utm_source=naver_blog&utm_medium=blog_menu" target="_blank"><img src="이미지주소" width="150" height="166"></a>
   ```
4. **다음** → 미리보기 확인 → **등록**
5. 같은 방법으로 나머지 4개 등록

   **위젯명 `지능형 제어반`**
   ```html
   <a href="https://donginensis.com/?utm_source=naver_blog&utm_medium=blog_menu#product" target="_blank"><img src="이미지주소" width="150" height="166"></a>
   ```
   **위젯명 `진단 신청`**
   ```html
   <a href="https://donginensis.com/manufacturing.html?utm_source=naver_blog&utm_medium=blog_menu#inquiry" target="_blank"><img src="이미지주소" width="150" height="166"></a>
   ```
   **위젯명 `IT기업 협업`**
   ```html
   <a href="https://donginensis.com/partner.html?utm_source=naver_blog&utm_medium=blog_menu#inquiry" target="_blank"><img src="이미지주소" width="150" height="166"></a>
   ```
   **위젯명 `회사소개서`**
   ```html
   <a href="https://donginensis.com/files/DONG-IN-ENSIS_Company-Profile_KR.pdf" target="_blank"><img src="이미지주소" width="150" height="166"></a>
   ```
6. 등록한 위젯 5개가 레이아웃 그림에 나타납니다. **마우스로 끌어서** 사이드바의 프로필 바로 아래로 옮기기 (홈페이지 → 지능형 제어반 → 진단 신청 → IT기업 협업 → 회사소개서 순)
7. **적용** 클릭

> 사이드바가 너무 길어 보이면 버튼 5개 대신 `banner-inquiry.png`(진단 신청), `banner-partner.png`(협업 문의) 2개만 넣어도 됩니다. 코드는 같고 `width="170"` 정도로 바꾸면 됩니다.

## 7단계. 카테고리 — 5분

**관리 → 메뉴·글·동영상 관리 → 블로그** (카테고리 관리)

1. **+ 카테고리 추가** 를 눌러 아래 순서대로 만들기

   | 카테고리 | 들어갈 글 |
   |---|---|
   | 지능형 제어반 | 제품, 도입 절차, FAQ |
   | 설비 데이터·스마트팩토리 | 데이터 수집, 예지보전, 지원사업 |
   | IT기업 협업 | MES·AI 연동, 데이터 API |
   | 조선·수소 | 선박·수소 제어 |
   | 납품 사례 | 프로젝트 소개 |
   | 회사 소식 | 인증, 선정, 보도자료 |

2. 각 카테고리: 공개 설정 **공개**, 주제 분류 **비즈니스·경제**
3. 예전 카테고리는 지우지 말고 그대로 두거나 맨 아래로 내립니다 (지우면 예전 글 주소가 꼬일 수 있음)
4. **확인** 클릭

## 8단계. 마무리 확인 — 5분

- [ ] PC에서 내 블로그 열기 → 상단 배너가 잘리지 않고 보이는지
- [ ] 사이드 버튼 5개를 하나씩 눌러 홈페이지 해당 페이지가 새 창으로 열리는지
- [ ] 회사소개서 버튼 → PDF가 열리는지
- [ ] 휴대폰 네이버 앱으로 블로그 열기 → 프로필 사진·블로그명·소개글이 맞는지
      (휴대폰에서는 PC 배너와 사이드 버튼이 보이지 않는 것이 정상입니다)
- [ ] 1단계의 "디자인 이미지 보관용" 글은 **비공개 상태로 그대로 두기** (지우면 버튼 이미지가 사라짐)

## 9단계. (선택) 휴대폰 화면 꾸미기

휴대폰 **네이버 블로그 앱** → 내 블로그 → **홈편집** → 커버 이미지에 `hero.png` 등록, 커버 스타일은 글자가 가려지지 않는 것으로 선택.
